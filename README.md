# C Embedded Testing Practice

This is a self-learning project for practicing C programming, debugging, and basic software testing concepts for embedded-style functions.

## Purpose

The purpose of this project is to strengthen my C programming fundamentals and understand how basic testing can be applied to embedded-style logic.

## Features

- Sensor value validation
- System status classification
- Error code handling
- Boundary value testing
- Expected vs actual result comparison
- Modular programming using header and source files

## Technologies

- C
- GCC
- VS Code
- Git/GitHub

## C Concepts Practiced

- Functions
- Arrays
- Structs
- Enums
- Pointers basics
- Conditional statements
- Modular programming with `.h` and `.c` files

## Testing Concepts Practiced

- Unit testing concept
- Test case design
- Normal input testing
- Boundary value testing
- Invalid input testing
- Expected vs actual result comparison
- Basic code coverage concepts: statement coverage, branch coverage, function coverage
